# Session catalogue

> 🔧 The reusable sessions of this plan, each with a **code**. Week sheets and
> log sheets refer to the code instead of restating the session — so changing a
> session in one place changes it everywhere.
>
> ⛔ No pace numbers here. Paces live in
> [`athlete/zones-and-paces.md`](../athlete/zones-and-paces.md) and nowhere else.

## Naming

```
EASY            easy run
REC             recovery run
EASY+ST         easy run + strides
LONG            long run
THR-3x8         threshold, 3 blocks of 8 minutes
VO2-5x3         VO₂max, 5 × 3 minutes
RP10-5x1000     10 km race pace, 5 × 1000 m
SPD-10x200      speed, 10 × 200 m
HILL-6x45       hills, 6 × 45 seconds
🏁 RACE          competition
```

---

## `EASY` — easy run

**Purpose:** aerobic base. 80 % of weekly volume lives here.
**Structure:** continuous, flat to rolling.
**Pace / HR:** see the *Easy* row of the pace table.
**Red line:** if average HR exceeds the ceiling, you are running it too fast —
that is not a small deviation, it is the difference between recovery and fatigue.

## `REC` — recovery run

**Purpose:** move blood, nothing else. The day after a hard session.
**Red line:** ⛔ nobody has ever gained fitness by running a recovery run at easy
pace. If it feels comfortable, slow down further.

## `EASY+ST` — easy run + strides

**Structure:** easy run + 6 × 100 m relaxed acceleration, full recovery.
**Purpose:** keep the legs able to turn over, at negligible fatigue cost.

## `LONG` — long run

**Purpose:** endurance, and the ability to run tired.
**Pace / HR:** slower than an easy run. See the warning in the pace table.

## `THR-<n>x<min>` — threshold

**Purpose:** raise the pace you can hold for an hour. The single most productive
session for distances from 10 km to marathon.
**Structure:** 20' warm-up + n blocks of m minutes at threshold, recovery 2-3',
+ 10' cool-down.
**Success criterion:** the last block within 3 s/km of the first. A threshold
session that drifts was run above threshold.

## `VO2-<n>x<min>` — VO₂max

**Purpose:** raise the ceiling. 3 to 5 minute efforts.
**Structure:** 20' warm-up + n × m minutes, recovery equal to the effort,
+ 10' cool-down.
**Caution:** expensive to recover from. Two per week is one too many.

## `RP10-<n>x<dist>` — race pace

**Purpose:** the link between threshold work and the race itself. Learn what the
target pace *feels* like, and prove you can hold it.
**Structure:** 20' warm-up + n × distance at goal race pace, short recovery,
+ 10' cool-down.
**Success criterion:** every rep inside the target window, and the **mean HR**
of each rep inside its window. ⚠️ Peak HR at the end of a rep is not a steering
signal — the average is.

## `SPD-<n>x<dist>` — speed

**Purpose:** running economy and leg speed. Short, fast, fully recovered.
**Caution:** the most seductive session and the least productive one for an
endurance goal. If most of your quality sessions are here, that is the finding,
not the plan.

## `HILL-<n>x<sec>` — hills

**Purpose:** strength without the impact of track work.
**Structure:** 20' warm-up + n × s seconds uphill hard, jog down as recovery.

## `🏁 RACE`

**Purpose:** the only honest measurement. Worth more than any benchmark session.
