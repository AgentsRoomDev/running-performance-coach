# Analysis reports

Dated, standalone reports: a baseline assessment, a feasibility study, a block
review, a race debrief.

> 🔒 **A report is dated and immutable.** You never edit last month's report; you
> write a new one. The series is the record of what was believed *at the time* —
> and being able to see that the coach was wrong in September is worth more than
> a tidy file that was quietly corrected in October.

```
analyses/
├── 2026-08-25-baseline.md
├── 2026-08-25-feasibility-sub-34.md
└── 2026-09-20-block-review-1.md
```

Naming: `YYYY-MM-DD-<short-slug>.md`.
Template for block reviews: [`../templates/block-review.md`](../templates/block-review.md).
